# Computer Science — 50 Detailed Notes

An undergraduate-level study collection covering fundamentals, practical examples, complexity and tradeoffs, common mistakes, and revision questions with answers. Examples use Python, SQL, TypeScript, or pseudocode where helpful.

Each note stands alone. Curated wikilinks connect only directly relevant concepts, with a short explanation of each relationship. The contents links remain ordinary Markdown links to avoid creating a graph hub. Notes are organized into subject folders. Follow the numbered sequence for a broad course, or use the folders below for focused revision.

Wikilink targets include their subject folder and are relative to this collection’s root. Open `computer-science-notes` as the notes folder.

## Suggested study method

1. Read the core idea and essential concepts.
2. Work through the example and explain why it works.
3. Review the assumptions and common mistakes.
4. Answer the revision question before reading its answer.
5. Follow the related links to connect topics.
