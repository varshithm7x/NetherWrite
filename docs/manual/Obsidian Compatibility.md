# Obsidian Compatibility

NetherWrite can open an existing Obsidian vault because the shared foundation is the folder: Markdown notes, attachments, and portable Canvas files.


## Why it exists

Changing tools should not require abandoning years of writing. Compatibility lets you evaluate NetherWrite from the same files you already own.

## When to use it

Use this guide before opening an existing vault, enabling a plugin, or moving a workflow from Obsidian.

## Workflow

Back up vault → open the same folder → inspect a few notes and links → test a plugin in a copy → keep both tools available while you evaluate.

## What carries over

| Item | NetherWrite approach |
| --- | --- |
| Markdown notes | Open directly |
| Wiki links | Read as vault links |
| `.canvas` files | Open as portable boards |
| Plugins | Compatibility runtime with permission prompts |

> **NetherWrite tip**
> Start with a copy of the vault if you are testing plugins or bulk operations.

> **NetherWrite common mistake**
> Plugin compatibility is not a promise that every community plugin behaves identically. Test the workflow you depend on.
