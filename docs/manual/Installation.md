# Installation

NetherWrite is a desktop app for macOS, Windows, and Linux. Install it, then choose a folder. No account is required for local writing.


## Why it exists

The desktop app gives Markdown files a fast editor, graph, canvas, and thinking layer without moving them into a hosted database.

## When to use it

Install NetherWrite when you want a local workspace for an existing folder or a new personal vault.

## Workflow

Download → install → launch → [choose a folder](<Open a Vault.md>) → create a note.

## Install

| Platform | Package |
| --- | --- |
| macOS | `.dmg` or `.zip` |
| Windows | `.exe` installer or portable executable |
| Linux | `.AppImage`, `.deb`, or Arch package |

Get the current build from [GitHub Releases](https://github.com/varshithm7x/NetherWrite/releases).

> **NetherWrite tip**
> Keep the application and your vault separate. Updating NetherWrite should never replace your notes.

> **NetherWrite common mistake**
> An installer changes the application, not your vault. Open a vault only after you know which folder you intend to use.
